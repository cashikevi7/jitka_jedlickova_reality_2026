# Kontext projektu pro AgenticSeek

**Projekt:** Mamka Reality  
**O čem:** Osobní web realitní makléřky Jitky Jedličkové (ČR). Statický marketingový web — jedna hlavní stránka + detail nabídek nemovitostí. Rodinný byznys, smluvní partner Reality Proradost s.r.o.

**Cíl:** Pastva pro oči a zážitek. Ambice: jeden z nejhezčích realitních webů (ČR i svět).

**Stack:** Next.js 15 (static export), React 18, Tailwind 4, Framer Motion, PhotoSwipe, Leaflet.

**Při startu:** Načti **[PROJECT.md](../PROJECT.md)** v kořeni repa — obsahuje plný kontext, strukturu, příkazy a odkaz na pravidla agenta v `.opencode/soul/`.

**Docker:** V tomto repu spusť `docker compose up` — služba `web` nasadí statický web (port v compose, např. 4102:80).
