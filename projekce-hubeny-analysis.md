# 🎯 Doporučený design směr pro nový web

## Vizuální identita:
- **Styl:** Moderní, čistý, důvěryhodný, profesionální
- **Vizuální jazyk:** Architektonická fotografie, čisté linie
- **Pocit:** Kvalita, preciznost, zkušenost, důvěryhodnost

## Barevná paleta:
- **Primární:** Tmavá šedá/černá (#1a1a1a, #2d2d2d) nebo béžová/krémová (#f5f5f0, #e8e6e1)
- **Akcent:** Měděná, bronzová nebo zlatá pro luxusní pocit
- **Text:** Tmavá na světlém / Bílá na tmavém

## Typografie:
- **Headings:** Moderní sans-serif (Inter, Söhne, custom geometric)
- **Body:** Čitelný sans-serif nebo elegantní serif pro kontrast
- **Velikosti:** Bold headings, comfortable reading size

## Layout patterns:
1. **Hero section:** Full-screen architektonická fotografie s overlay textem
2. **Services:** Grid nebo cards s ikonami
3. **Projects:** Masonry grid nebo carousel s hover efekty
4. **About:** Split layout (text + image)
5. **Contact:** Clean form nebo kontaktní informace s mapou

## Interakce:
- Smooth scroll
- Subtle parallax
- Hover efekty na projektech
- Elegantní page transitions
- Scroll-triggered animations

## Struktura navrhovaného webu:
1. **Hero** - Fullscreen image + hlavní claim
2. **O mně** - Filozofie + zkušenosti
3. **Služby** - 4 kategorie s detaily
4. **Projekty** - Portfolio realizací
5. **Proces** - Jak spolupráce probíhá
6. **Kontakt** - Formulář + info
